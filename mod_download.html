How to Install Star Fox: Event Horizon

Follow these steps to download and play the fangame.

1. Download Knossos.NET

Event Horizon is distributed through the Knossos mod manager. Download the latest version of Knossos.NET below:

Download Knossos.NET

2. Search for “Event Horizon”

Go to the Explore tab and type StarFox Event Horizon in the search bar. Select the mod from the list.

3. Install the Mod

Click Install. Knossos will automatically download:

  • Make sure to select which storage drive you want to download.
  • Event Horizon mod files
  • Required FreeSpace Open engine
  • All dependencies

4. Launch the Game

Once installed, click Play inside Knossos to launch Star Fox: Event Horizon.
